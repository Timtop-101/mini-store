MINI STORE AI v2 — игровой магазин для iPhone и iPad

БЫСТРЫЙ ЗАПУСК
1. Загрузите index.html, app.js, icon.svg, manifest.webmanifest и sw.js в репозиторий GitHub Pages.
2. Включите GitHub Pages для этого репозитория.
3. Откройте HTTPS-сайт в Safari на iPhone/iPad и выберите «Поделиться» → «На экран Домой».
4. Дайте разрешение на камеру/микрофон по запросу. Для сканирования без сервера сначала добавьте фотографии коробок в «Обучение».

РАБОТАЕТ БЕЗ ИИ-СЕРВЕРА
- Каталог 17 товаров с заданными игровыми ценами, корзина и оплата.
- Локальный чат на основе команд и прайса (не большая языковая модель).
- Голосовой ввод через Web Speech API — зависит от браузера и ОС, может быть недоступен или требовать интернет.
- Озвучивание ответов через браузер (speechSynthesis) при поддержке.
- Сканирование по примерам: простой алгоритм сходства изображений (НЕ нейросеть), возможны ошибки.

НАСТОЯЩИЙ ОБЛАЧНЫЙ ИИ (НЕОБЯЗАТЕЛЬНО)
В архиве есть ai-worker.js — пример защищённого шлюза для Cloudflare Workers.
1. Создайте Cloudflare Worker и вставьте туда код из ai-worker.js (ES module).
2. Создайте секрет OPENAI_API_KEY в настройках Worker. Никогда не вставляйте ключ в app.js или HTML.
3. Задайте переменную ALLOWED_ORIGIN — точный origin вашего сайта (например, https://USERNAME.github.io, БЕЗ косой черты на конце).
4. При необходимости задайте OPENAI_MODEL модель с поддержкой изображений, например gpt-4.1-mini.
5. Разверните Worker на HTTPS-адресе. В приложении: ИИ → Подключение ИИ → укажите HTTPS-адрес Worker.
6. Отправляемые фото/сообщения обрабатываются внешним сервисом. Могут возникать затраты на API. Не используйте чужие ключи.

Серверный пример подходит для личной игры. Для общедоступного проекта добавьте аутентификацию и rate limiting, иначе чужие люди могут расходовать ваш бюджет API. Проверка Origin сама по себе не является защитой от прямых API-запросов.

РАСПОЗНАВАНИЕ
Облачный анализ предлагает возможную модель, НЕ гарантирует точность. Подтверждайте товар перед добавлением в корзину. На iPhone/iPad файл сохраняет локальные данные каждого устройства отдельно; корзина между устройствами не синхронизируется.
